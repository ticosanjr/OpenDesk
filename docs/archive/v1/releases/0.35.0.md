## OpenDesk v0.35.0

### CLI headless
- O binário `opendesk` agora aceita subcomandos:
  - `status`
  - `workspaces list`
  - `tasks list`, `tasks create`, `tasks run`
  - `runs list`, `runs show`
  - `queue list`
  - `export <run-id>`
- Saída humana compacta ou `--json`.
- Flags para workspace, agente, modelo, modo, prioridade, tags e limite.
- O CLI usa a API local com Bearer token; não abre o banco nem duplica execução.

### Export de sessão
- Export por execução em **Markdown**, **HTML autocontido** e **JSON**.
- O export inclui status, agente, modelo, duração, tokens, custo, resultado,
  passos, raciocínio, ferramentas e artefatos.
- Botões `MD`, `HTML` e `JSON` na página de detalhe da execução.
- Endpoint `GET /api/runs/{id}/export?format=md|html|json`.
- Download com nome seguro e conteúdo escapado no HTML.

### Qualidade
- Testes: **312 Rust**, **122 Vitest** e **51 Playwright**.
- Clippy `-D warnings`, TypeScript, Vitest e E2E verdes.
