## OpenDesk v0.28.0

### Interação
- Os comboboxes de agente, modelo e receita compartilham a mesma regra de fechamento por foco (`shouldCloseOnBlur`).
- Saíram os `setTimeout` de blur que podiam desmontar o dropdown durante um clique.
- O comportamento agora é determinístico em mouse, teclado e automação Playwright.

### Studio
- A instalação de conteúdo usa `StudioKind` em vez de comparar strings soltas.
- A interface `StudioItem` ganhou cobertura para parse de kinds, paths, listagem, toggle e delete dos quatro tipos.
- Novos testes cobrem list/get/delete de agent, skill e command, além do round-trip de `opencode.jsonc`.

### Qualidade
- Testes: 265 Rust, 93 Vitest e 41 Playwright.
- Cobertura Rust: 60,23% global e 66,37% core; Vitest com 97,55% de linhas.
- Gate completo, build e publicação executados sem release candidate intermediária.

### Correções
- A busca global não regrava mais o hash depois que o usuário abre um resultado; o debounce agora respeita a rota atual e o deep link do Kanban abre a tarefa corretamente.

### Base da versão
- Mantém calendário com visões de mês/semana/7 dias/dia, cards consistentes, limites reais de 20 MB, timezone do sistema e a configuração efetiva unificada do Studio.
