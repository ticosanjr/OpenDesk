# OpenDesk 1.1.0

Fecha as pendências de autenticação e operação de terminal que ficaram fora do
corte 1.0.0, sem mudar o control plane.

## Passkeys (WebAuthn)

- Cadastro e login por passkey no PWA, com fallback por token.
- Cerimônias guardadas no servidor, uso único e TTL de 10 minutos.
- Credenciais no SQLite; o login emite a mesma sessão revogável de 30 dias.
- Origem/RP ID derivados da requisição, com HTTPS obrigatório fora de
  localhost e erro explícito para IP.
- Configurações → Segurança lista, cadastra e remove passkeys.
- Migração 0048; ADR 0073.

## Bootstrap compartilhado

- `control_plane::start` inicializa daemon, integrações, watcher, fila, cron,
  push, manutenção, IO bus, receitas, governança, triggers, starter packs e MCP
  bridges para desktop e `opendeskd`.
- O desktop ficou responsável apenas por janela, tray, atalhos e shutdown.
- O servidor Axum não depende mais de `tauri::async_runtime`.

## TUI

- `opendesk tui` com `tasks`, `runs`, `approvals`, `queue`, `nodes`,
  `diff <run>`, `approve/deny <id>` e `exit`, usando a mesma API local.
- `opendesk nodes list` já disponível.

## Verificação

- Suíte Rust, Vitest, ESLint, `tsc` e goldens visuais verdes.
- Notas e decisões em ADRs 0073–0074.
