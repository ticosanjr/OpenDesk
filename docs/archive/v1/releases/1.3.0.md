# OpenDesk 1.3.0

Esta é a primeira release depois da 1.2.0. O foco é consolidar o control plane,
a execução isolada, o gateway MCP e o caminho headless.

## Destaques

- **Core sem Tauri** para receitas, fila, cron, lease, settlement e MCP.
- **Daemon, CLI e node headless**: `opendeskd`, `opendesk-cli` e `opendesk-node`
  compilam sem a feature `desktop`.
- **Worktrees**: UI para listar/diff/mesclar/descartar e experimentos A/B com
  dois worktrees e escolha aprovada.
- **MCP**: Streamable HTTP/SSE com sessões, proxy de servidores externos,
  RBAC/rate/audit, elicitation e sampling.
- **Eval**: casos curados, replay sombra sem ferramentas, thresholds,
  promoção e rollback de skill.
- **Receitas**: `loop` limitado com caminhos duráveis, `switch` e árvore de nós.
- **Multi-node**: TLS mútuo com reload, sync delta por job e recuperação de
  lease sem duplicar job.
- **Chat**: resposta de e-mail com anexos, inbound IMAP criando thread e
  push-to-talk/TTS.
- **Empacotamento**: RPM separado do `opendeskd` com systemd user unit.

## Instalação Linux

Artefatos em `releases/1.3.0/`: `.deb`, `.rpm`, AppImage, `opendeskd` e
checksums. O `.deb` inclui o daemon e a unit; o RPM do daemon é separado.

```bash
sudo dpkg -i opendesk_1.3.0_amd64.deb
# ou
sudo rpm -i opendesk-1.3.0-1.x86_64.rpm
sudo rpm -i opendeskd-1.3.0-1.x86_64.rpm
systemctl --user enable --now opendeskd
```

## Limitações conhecidas

- Esta release foi gerada e validada em **Linux**. MSI/NSIS (Windows) e DMG
  (macOS) exigem máquinas nativas, certificados e validação manual; não estão
  incluídos.
- WhatsApp, voz contínua e computer-use Windows/macOS continuam pendentes.
- A validação manual de Google/Telegram/Signal/WhatsApp/áudio e de duas máquinas
  reais não foi executada neste ambiente.
- O container sandbox não foi validado por falta de permissão no Docker/Podman.
- A cobertura Rust está no piso acordado de 53,8% total / 62,7% core, não em
  80%.
- A9 (reexports do shell) permanece como limpeza cosmética.
