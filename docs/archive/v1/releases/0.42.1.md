## OpenDesk v0.42.1

### Correção crítica de foco nos formulários
- Corrigido o `Modal` compartilhado que roubava o foco a cada tecla.
- O efeito de foco agora depende apenas de `open`; `onClose` é lido por ref,
  então re-renders dos campos não refocam o botão de fechar.
- Ao abrir, o foco vai para o primeiro campo de formulário (não para o X).
- O timer de foco é cancelado no cleanup e o foco anterior é restaurado apenas
  ao fechar.
- Tab/Shift+Tab tratam corretamente o foco no próprio diálogo.
- Vale para todos os diálogos: tarefa, rotina, receita, workspace, evento,
  confirmação, integrações, Studio, governança e configurações.

### Testes
- Novo teste Vitest do `Modal` com input controlado e `onClose` instável:
  digitação mantém o foco e Escape usa o callback mais recente.
- Novo E2E `modal-focus.spec.ts` digitando com `pressSequentially`
  (“Tarefa com espaço”) para reproduzir o bug em teclas reais.
- Suíte E2E ganhou headroom de rate limit para evitar flakes por rajadas de
  requisições; o limitador real continua ativo em produção.
