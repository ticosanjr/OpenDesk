descreve o estado atual do código.

- `releases/` — notas das releases V1.
- `sources/` — documentos de origem que foram fundidos em `SPEC.md`:

O estado atual está em `SPEC.md`, `ARCHITECTURE.md`, `DESIGN.md` e
`docs/decisions/` (a partir do ADR 0200). Não edite este arquivo para refletir
