# OpenDesk 0.59.0

Release de organização da configuração de prompts e de memória explícita: a
aba Prompt foi dividida por finalidade, a cobertura de templates ficou completa
e o MCP passou a separar aprendizado de contexto pessoal.

## Configurações → Prompt

A aba agora tem três seções:

- **Templates de prompts** — todos os textos automáticos editáveis.
- **Prompts enviados** — preview das tarefas.
- **Prompts de chat** — preview de Desktop, Telegram e Signal.

Os dois previews usam a mesma ordem de abas:

1. **Seções**
2. **OpenDesk**
3. **OpenCode**
4. **Final reconstruído**

O preview de chat ganhou a aba OpenCode com agente, `AGENTS.md`, skills,
comandos e servidores MCP.

## Cobertura de templates

- `chat_channel` é o prompt do chat por canal.
- Novos templates:
  - **Política de memória** (`memory_policy`);
  - **Correção de step de receita** (`recipe_feedback`);
  - **Teste de modelo** (`model_test`).
- Tarefa, rotina e receita usam os mesmos templates de composição; o conteúdo
  específico de uma receita/rotina continua no editor do próprio item.
- A camada nativa do OpenCode permanece somente leitura.

## Memória via MCP

- **`learning_save`**: salva um aprendizado em `learning_lessons`; com
  `remember=true`, também grava no `MEMORY.md`. É o destino padrão para
  “memorize isto”.
- **`personal_context_save`**: só deve ser usado com pedido explícito do
  usuário; exige `user_request` com a citação literal.
- Contexto pessoal passa a registrar `source` (`manual`/`agent`) e
  `source_quote` (migração 0041); a UI mostra “via agente” e o pedido.
- O template de política de memória é incluído em tarefas e chat, reforçando:
  aprendizado por padrão, contexto pessoal somente sob pedido explícito.
