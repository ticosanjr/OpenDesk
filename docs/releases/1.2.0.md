# OpenDesk 1.2.0

Fecha a onda 8 de verdade: o protocolo multi-node ganhou um cliente executável e
o release passou a distribuir o daemon.

## Worker remoto

- `opendesk node run --central <url> --token <token> [--once] [--poll <s>]`.
- Heartbeat, claim de job, execução no workspace compartilhado, heartbeat
  durante o run e `complete` com run/uso/resumo.
- Harnesses: Claude Code, Codex, Pi e Hermes. Jobs OpenCode são recusados com
  explicação (exigem daemon local).
- Token via `OPENDESK_NODE_TOKEN` (recomendado) ou `--token`.

## Distribuição

- O release agora inclui `opendeskd-<plataforma>`, além do binário desktop e
  instaladores `.deb`/`.rpm`/AppImage.
- O updater do desktop continua escolhendo apenas o asset `opendesk-<plataforma>`.

## Verificação

- Suíte Rust, Vitest, ESLint, `tsc` e goldens visuais verdes.
- Testes do mapeamento de harnesses do worker.
- ADR 0075.
