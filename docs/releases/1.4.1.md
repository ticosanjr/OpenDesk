# OpenDesk 1.4.1 — abertura com banco V1 e empacotamento do daemon

Hotfix da 1.4.0. A fundação V2 continua igual; esta release corrige a primeira
abertura para quem ainda tem um banco V1 e o empacotamento do daemon.

## Correções

- **Banco V1 não fecha mais o app em silêncio.** Antes de criar a janela, o tray
  ou os locks, o OpenDesk detecta o banco V1 e mostra um diálogo nativo:
  - **Exportar e continuar**: exporta workspaces, receitas e settings para
    `~/.local/share/opendesk/v1-export-<data>/`, preserva o banco antigo como
    `opendesk.db.v1-<data>` (com `-wal`/`-shm`) e relança o app com um banco V2
    novo.
  - **Sair**: não toca em nada.
- **Janela só aparece quando o backend está pronto.** A janela principal nasce
  oculta; ela e o tray aparecem depois da inicialização. Falhas de startup
  agora mostram um diálogo em vez de piscar e desaparecer.
- **Comando de export no binário desktop:** o AppImage não traz o
  `opendesk-cli`, então o mesmo export passou a existir em:

  ```bash
  opendesk migrate-v1-export [--db <v1.db>] [--out <dir>] [--format json|yaml]
  ```

  Sem argumentos, usa o banco do app e exporta para
  `~/.local/share/opendesk/v1-export-<data>`.
- **Empacotamento do daemon:** `scripts/release.sh` reconstrói o `opendeskd`
  sempre e o RPM do daemon é limpo antes de gerar, evitando publicar um binário
  antigo junto do desktop novo. A 1.4.1 inclui o daemon V2 correto.

## Recuperação manual (se preferir)

```bash
opendesk migrate-v1-export
# e mova o banco antigo:
mv ~/.local/share/opendesk/opendesk.db{,.v1}
```

## Verificação

- Testes de storage cobrem detecção V1, export JSON/YAML, recusa de banco V2,
  backup do `.db`/`-wal`/`-shm` e criação do V2 após a migração.
- Export testado contra uma cópia de um banco V1 real (6 workspaces, 25
  receitas, 14 settings).
- Gate completo verde; daemon empacotado cria o schema V2 (62 tabelas com
  `v2_meta`, sem `chat_threads`).

## Limitações

- Ondas 2–4 seguem incompletas (god-files no core, event-driven, extinção do
  core, shell/frontend/doctor, 75% de cobertura).
- Release Linux; MSI/NSIS e DMG continuam externos.
