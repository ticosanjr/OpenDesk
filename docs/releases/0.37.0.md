## OpenDesk v0.37.0

### Backup completo do workspace
- Backup `.zip` de todo o workspace: `input/`, `output/`, `.opencode/`,
  `opencode.jsonc`, README e demais arquivos.
- Exclusão automática de `node_modules`, `.git`, `target`, `dist`, caches e
  ambientes virtuais.
- Manifesto com versão, contagem de arquivos, bytes e SHA-256.
- Verificação de integridade antes de restaurar.
- Restauração sempre como **novo workspace**, com destino vazio ou inexistente;
  o workspace atual nunca é sobrescrito.
- Proteções contra zip-slip, symlinks, caminhos absolutos, limite de 2 GiB e
  100 mil arquivos.

### Interfaces
- Nova aba **Configurações → Backups**: criar, listar, baixar, restaurar e
  excluir.
- CLI:
  - `opendesk backups list`
  - `opendesk backups create`
  - `opendesk backups restore <id> --path <diretório>`
  - `opendesk backups download <id> --out <arquivo>`
  - `opendesk backups delete <id>`

### Qualidade
- Testes: **319 Rust**, **124 Vitest** e **53 Playwright**.
- Clippy `-D warnings`, TypeScript, cobertura e E2E verdes.
