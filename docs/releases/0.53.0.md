# OpenDesk 0.53.0

Release de conectividade remota e acabamento do AppImage: bot do Telegram,
atalho correto no menu/barra de tarefas e um fluxo de verificação/release muito
mais rápido.

## Telegram

- Bot por **long polling**, sem webhook, túnel ou URL pública.
- Token do bot no secret store criptografado (AES-256-GCM, `0600`); nunca
  retornado pela API nem escrito em logs.
- Allowlist obrigatória por **chat ID** (inclusive grupos) ou **@username**.
- Chat com o agente pelo celular, com thread `Telegram · …` no histórico.
- Comandos `/start`, `/help`, `aprovar <prefixo>` e `negar <prefixo>`.
- HITL de receitas e pedidos de permissão do OpenCode também chegam no Telegram.
- Notificações de rotinas (`notify_telegram`), destinatários, teste de aviso,
  badge no card e canal `TELEGRAM` no histórico de entregas (migração 0035).
- Nova aba **Integrações → Telegram** com token, allowlist, workspace, agente,
  status do bot, iniciar/parar, enviar teste e remover token.
- Offset de `getUpdates` persistido; trocar o token não repete mensagens do bot
  anterior.

## AppImage e barra de tarefas

- O AppImage no Linux cria/atualiza automaticamente
  `~/.local/share/applications/opendesk.desktop`, com ícone absoluto extraído de
  `$APPDIR` e `StartupWMClass=Opendesk`.
- Corrige a engrenagem genérica exibida pela lista de janelas do Cinnamon; o
  ícone agora é o mesmo do tray e da interface.
- Botão **Reintegrar atalho** em Configurações → Sobre.
- A escrita é idempotente e acompanha o AppImage quando ele é movido.

## Verificação e release

- `npm run verify` passou a ser a checagem padrão: fmt/clippy/testes Rust quando
  há `.rs` e ESLint/TypeScript/Vitest quando há frontend.
- O release padrão usa verificação proporcional e perfil rápido de build (thin
  LTO, `codegen-units=16`, incremental).
- O cache de `src-tauri/target` é preservado; `clean.sh --all`/`--deep` fazem a
  limpeza real.
- O AppImage reaproveita o AppDir montado e roda só o `appimagetool` (~9 s);
  `linuxdeploy` só volta a rodar quando bibliotecas, configuração ou ícones
  mudam.
- Flags novas: `--quality-build`, `--no-appimage`, `--refresh-appimage`,
  `--reuse-build` e `--clean`.

## Verificação

- `npm run verify` verde.
- 410 testes Rust e 222 Vitest.
- E2E da página de Integrações cobre a nova aba Telegram.
- Teste manual do atalho em sessão gráfica real: `.desktop`, ícone e
  `mimeinfo.cache` gerados corretamente.

## Notas

- O OpenDesk precisa estar rodando (desktop ou `--headless`) para o bot
  responder.
- Crie o bot no `@BotFather`, cole o token, envie `/start` do celular e só
  depois adicione o chat ID/@username à allowlist.
- A primeira versão do Telegram cobre texto e comandos; áudio, fotos e
  documentos ficam para depois.
- Um atalho já fixado antes desta versão pode precisar ser removido e fixado de
  novo uma vez.
- Testes manuais pendentes: conversar com bot real, aprovar permissão/HITL,
  receber aviso de rotina e confirmar visualmente a barra de tarefas no
  Cinnamon.
