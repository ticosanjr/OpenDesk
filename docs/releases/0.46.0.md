## OpenDesk v0.46.0

### Modelos do roteador agora são do OpenDesk
- O roteador deixou de ler o `model` do `opencode.jsonc`. O modelo padrão e o
  modelo do modo Manual são escolhidos na tela **Roteador & Custos** e salvos
  por workspace.
- `POST /api/router/models` persiste `default_model` e `manual_model`; o
  `GET /api/router/config` devolve os dois. Nada é lido ou escrito no
  `opencode.jsonc` para decidir o modelo.
- Precedência no modo Manual: modelo do card da tarefa → modelo manual do
  workspace → modelo padrão do workspace → primeiro modelo disponível no motor.
- O fallback da fila e as rotinas usam o modelo padrão do workspace, não um
  `opencode-go/*` fixo.

### Teste em cada modalidade
- Nova tabela **Teste das modalidades** com as cinco políticas
  (`COST_BENEFIT`, `CHEAPEST`, `BEST_QUALITY`, `MANUAL`, `CUSTOM_RULES`).
- Cada linha tem **Testar** (classificador local, zero tokens) e mostra origem,
  agente, modelo, effort, fase, regra aplicada, disponibilidade do modelo e
  quantidade de modelos no motor.
- **Testar todas** preenche a tabela de uma vez.
- Cada resultado tem **Testar modelo** para validar a conexão do modelo
  resolvido naquela modalidade.
- Regras IF-THEN continuam com criação e edição; a tabela funciona mesmo com o
  motor offline.

### Teste de modelo mínimo
- `POST /api/models/test` não cria mais sessão, agente, histórico nem
  ferramentas. Usa `POST /api/experimental/generate/text` com o prompt
  `Output only: OK`.
- Cada teste consome apenas alguns tokens e devolve texto, latência e variante.
- Classificação separada: `engine_offline`, `engine_unsupported`,
  `provider_quota` (402/saldo), `rate_limited` (429), `auth_failed`,
  `model_not_found`, `timeout` e `provider_error`.
- `provider_quota` e `rate_limited` registram cooldown de 60 minutos e acionam
  o fallback, sem confundir erro do provider com falha do OpenDesk.
- O botão em todos os seletores de modelo agora se chama **Testar (mínimo)**.

### Verificação real
- Novo `npm run verify:model` sobe um OpenDesk headless, cria um workspace,
  salva o modelo padrão e executa uma geração mínima real.
- Verificado neste release com `deepseek/deepseek-flash` do OpenCode:
  resposta `OK`, engine online e `model_available: true` com 81 modelos.
