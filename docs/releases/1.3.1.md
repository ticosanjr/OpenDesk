# OpenDesk 1.3.1

Release de segurança, integridade e desempenho sobre a 1.3.0. Sem novas telas;
o foco é fechar falhas encontradas na auditoria e reduzir custo de I/O e
processos.

## Segurança

- **Webhook HTTP sempre autenticado**: `WEBHOOK_HTTP` exige `secret_ref`; fonte
  desativada, sem segredo ou com assinatura ausente/inválida responde 400.
  `config.secret` em texto puro é migrado para o `SecretStore` e o
  `trigger_config_json` da rotina perde o valor em claro. Rotinas usam
  `schedule-<id>` e receitas `recipe-<id>-<index>` como referência estável.
- **IMAP**: validação de certificado sempre ativa. O antigo `tls=false` não
  desliga mais a validação; certificado autoassinado exige
  `allow_invalid_certs: true`, explícito e avisado em log.

## Integridade

- **Merge de worktree overlay** usa manifesto sha256 criado com a run: não
  sobrescreve edição feita depois do início, aplica deleções da run e devolve
  `Conflict` sem escrita parcial quando os dois lados mudaram.
- **Merge git** exige índice limpo e deixa o `git merge --no-ff` criar o commit,
  sem capturar staging alheio; `git add`/`commit` verificam status.
- **Cleanup** devolve erro quando o diretório ou o branch continuam existindo e
  a API só marca `REMOVED` em caso de sucesso.
- **Backup pré-migração** faz `wal_checkpoint(TRUNCATE)` antes de copiar, para
  não perder páginas commitadas que ainda estavam no `-wal`.

## Desempenho

- Timeline de execução com cache incremental: polls leem só o que foi anexado
  ao JSONL, não o arquivo inteiro.
- `/api/runs/:id/log` lê 256 KB do fim com `seek`, fora do worker async.
- Resolução do binário do OpenCode com cache de 60 s invalidado por caminho e
  mtime; `/api/about` não bloqueia mais o runtime.
- Dashboard de governança agrega gasto mensal em uma query por workspace.
- SQLite em WAL com `synchronous=NORMAL`.
- Contador de segundos do chat isolado, sem re-renderizar a página inteira.

## Correções

- `/api/about` reporta a versão correta do Tauri (ou `headless`) e não roda
  `rustc`/`uname` a cada request.

## Release

- `scripts/release.sh` passa a usar LTO completo e `codegen-units=1` por padrão;
  `--fast-build` mantém thin LTO para iterações descartáveis.

## Instalação Linux

Artefatos em `releases/1.3.1/`: `.deb`, `.rpm`, AppImage, `opendeskd`, RPM do
daemon, binários portáteis, `latest.json` assinado e `SHA256SUMS`.

```bash
sudo dpkg -i opendesk_1.3.1_amd64.deb
# ou
sudo rpm -i opendesk-1.3.1-1.x86_64.rpm
sudo rpm -i opendeskd-1.3.1-1.x86_64.rpm
systemctl --user enable --now opendeskd
```

## Limitações conhecidas

- Release gerada e validada em **Linux**. MSI/NSIS e DMG continuam fora por
  exigirem máquinas nativas, certificados e validação manual.
- WhatsApp, voz contínua e computer-use Windows/macOS seguem pendentes.
- Container sandbox não validado neste host (Docker sem permissão, Podman
  ausente).
- Cobertura Rust no piso acordado de 53,8% total / 62,7% core, não em 80%.
- A9 (reexports do shell) permanece como limpeza cosmética.
- O gate completo (cobertura, 103 Playwright e goldens) não foi re-executado
  nesta rodada; a verificação foi proporcional, como padrão do projeto.

## Verificação

- 340 testes shell + 291 core = 631.
- Clippy `--all-targets --all-features -D warnings` limpo.
- `cargo check --no-default-features` ok.
- TypeScript, ESLint e 256 testes Vitest verdes.
- Playwright do fluxo IO bus/webhook reexecutado (2/2), incluindo POST sem
  assinatura recusado.
- `npm run verify` verde e `npm run audit:prod` sem vulnerabilidades de
  produção.
