# SEO on-page

## Quando usar
Ao planejar e revisar.

## Processo
1. Defina palavra-chave principal.
2. Escreva title e meta.
3. Use headings claros.
4. Sugira links internos.

## Checklist
- [ ] Não há repetição artificial.
- [ ] A meta description resume o valor.

## Anti-padrões
- Entregar texto genérico sem adaptar ao contexto recebido.
- Não esconder incertezas: marque o que é fato, inferência ou recomendação.
