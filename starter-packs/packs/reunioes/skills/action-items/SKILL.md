# Action items

## Quando usar
Ao fechar a ata.

## Processo
1. Comece com verbo.
2. Defina resultado.
3. Atribua dono e prazo.
4. Marque dependência.

## Checklist
- [ ] A ação é executável.
- [ ] O prazo é explícito.

## Anti-padrões
- Entregar texto genérico sem adaptar ao contexto recebido.
- Não esconder incertezas: marque o que é fato, inferência ou recomendação.
