# Divulgação progressiva

## Quando usar
Sempre que uma skill crescer além de um guia curto.

## Regras
- SKILL.md é o índice e o caminho feliz.
- Referências ficam a um nível de profundidade.
- Nomes de arquivo descrevem o conteúdo.
- Scripts são executados, não carregados inteiros.
- Cada arquivo referenciado tem propósito claro.
- Tabela de conteúdo em referências longas.
- Nada de `file1.md`, `docs/` genérico ou cadeia de links.

## Estrutura
```
SKILL.md
references/quickstart.md
references/advanced.md
scripts/validate.py
evals/cases.yaml
```
