# Onboarding de cliente

## Quando usar
Após fechamento.

## Processo
1. Kickoff.
2. Objetivo.
3. Marcos 7/30/60.
4. Responsáveis.
5. Check-in.

## Checklist
- [ ] O cliente sabe o próximo passo.
- [ ] Há marco mensurável.

## Anti-padrões
- Entregar texto genérico sem adaptar ao contexto recebido.
- Não esconder incertezas: marque o que é fato, inferência ou recomendação.
