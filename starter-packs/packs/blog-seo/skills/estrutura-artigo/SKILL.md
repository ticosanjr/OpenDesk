# Estrutura de artigo

## Quando usar
Antes de escrever.

## Processo
1. Tese em uma frase.
2. 3–5 seções.
3. Cada seção com evidência.
4. Fechamento acionável.

## Checklist
- [ ] O título promete o que o texto entrega.
- [ ] Cada seção avança a tese.

## Anti-padrões
- Entregar texto genérico sem adaptar ao contexto recebido.
- Não esconder incertezas: marque o que é fato, inferência ou recomendação.
